# Phase 6 - Deployment

## Deployment Method
- Platform: GitHub Pages
- Branch: main

## Steps
1. Push all code to GitHub main branch
2. Go to Repository Settings -> Pages
3. Select Source: Deploy from a branch
4. Select Branch: main and folder: / (root)
5. Click Save
